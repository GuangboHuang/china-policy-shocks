## 已验证的修改

通过网页读取核对四张卡片的7个官方入口；回填其中6个政策相关链接（4条政策）。生态环境部页面有2016年第一批8省区及进驻表；医保局答记者问和辽宁省医保局页面确认4+7范围与采购机制；证监会公告确认2019年1月28日公布即施行；USTR两页提供List 1–4导航与List 1行动通知入口。上海证券交易所科创板首页虽能读取，但未作为具体政策文件回填。

`verified_partial`表示网页内容支持台账所述事实，并非全条记录的全面认证。未逐一下载核验附件或重建处理组。2016环保督察只验证第一批；集采2018年启动不能直接当作医院实际执行时点；301目录不能代替各清单税率、生效日期与豁免数据。8条`pending`均已尝试读取Excel候选链接但未取得可核验正文；读取错误不能证明链接永久失效，也不表示政策不存在。原地址保存在台账`candidate_url`，主表暂留空，等待重新访问或找到替代官方文件。台账逐条列出需查的主管机关文件、名单或实施时序；无证据的主表字段继续留空。

其他21条来自Excel原有候选链接，逐条证据范围详见台账；其中既有原始文件，也有官方转载报道或报告，不能一概视为原始法规正文。网页日期`source_date`与政策落款、实施日期可能不同，差异记入`evidence`，本次未擅自改变原表政策时间。

同时修复生成脚本无法识别Excel原有“官方来源URL”及“备注/下一步核验”列名的问题，防止重新生成时静默丢失信息。Excel为维护源，CSV和附录已同步生成。保留v0.1文件名以兼容现有下载链接。

## 可复现检查与限制

```bash
pip install -r requirements.txt
python scripts/build_appendix.py
python scripts/check_data.py
```

检查字段、必填值、政策名唯一性、年份、等级、Excel/CSV逐值一致、附录一致、台账全覆盖、来源与卡片对应以及URL基本格式；实际运行文档Python示例。Stata只检查导入选项和字段存在性，未在Stata运行。CI离线检查不宣称链接永久有效，也不以HTTP成功或官方域名替代政策内容审核。以后补证需更新Excel和台账，并重新生成、检查。
